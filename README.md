<h2 align="center">A free Git client for Linux</h2>

<p align="center">
  <strong>Source is free and open source.</strong><br />
  It is a direct alternative to <a href="https://www.sourcetreeapp.com/">SourceTree</a> for Linux —
  the same idea, built for your desktop.
</p>

<p align="center">
  Source simplifies how you interact with your Git repositories so you can focus on coding.<br />

<h2 align="center" id="get-source-for-free">Get Source for free</h2>

<p align="center">
  <strong>100% free. 100% open source.</strong><br />
  The SourceTree-style Git experience, built for Linux.
</p>

<br />

<h3 align="center">Run from source</h3>

```bash
./gradlew run
```

<h3 align="center">Package for Linux</h3>

```bash
./gradlew packageDeb
./gradlew packageRpm
./gradlew packageAppImage
```

<p align="center">
  Requires Linux (x64 or arm64), JDK 15+, and Git on your system.
</p>
